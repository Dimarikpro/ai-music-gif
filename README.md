## Как обновить GitHub Pages
1. Распаковать архив.
2. Загрузить все файлы в репозиторий ai-music-gif с заменой.
3. Commit changes.
4. Через 1–2 минуты открыть сайт на телефоне.

## Куда класть медиа
- Фото: assets/images/
- Видео: assets/videos/
- Аудио: assets/audio/
